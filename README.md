<h1>MERN Stack E-Commerce Platform</h1>

A full-stack e-commerce web application built using the MERN stack. The platform provides an online shopping experience with product browsing, shopping cart management, user authentication, order processing, administrator controls and online payment integration.

<h3>Overview</h3>

This project is designed to simulate a real-world online shopping platform where customers can browse products, select items, manage their shopping carts and place orders through integrated payment gateways. 

The application also includes an administrator interface for managing products and monitoring customer orders.

The frontend communicates with a RESTful backend API, while MongoDB manages application data.
